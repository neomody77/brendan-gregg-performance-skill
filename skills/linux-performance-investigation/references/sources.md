# Official methodology sources

This repository synthesizes the methods in its own words; it does not copy book chapters or third-party articles. These are public pages by the author. Access to a link does not authorize redistribution of an entire work.

- [Performance Analysis Methodology](https://www.brendangregg.com/methodology.html): overview, problem statements, workload characterization, scientific methods, and related approaches.
- [USE Method](https://www.brendangregg.com/usemethod.html): utilization, saturation, and errors for each resource.
- [TSA Method](https://www.brendangregg.com/tsamethod.html): interpreting thread time through execution, queuing, paging, sleeping, locks, and idle states.
- [Off-CPU Analysis](https://www.brendangregg.com/offcpuanalysis.html): aggregating off-CPU time by blocking stacks.
- [Linux Performance Analysis in 60s](https://www.brendangregg.com/blog/2015-12-03/linux-perf-60s-video.html): initial Linux triage checklist.
- [Performance Checklists for SREs](https://www.brendangregg.com/blog/2016-05-04/srecon2016-perf-checklists-for-sres.html): layered checklists and method-driven investigation.
- [Active Benchmarking](https://www.brendangregg.com/activebenchmarking.html): observing components during a benchmark to explain its actual limiting factor.

The case measurements and scripts come from this project's independent experiment, not the author's presentations. The original checklists are older material; command fields and event support must be verified on the target system.
