# 官方方法来源

本仓库用自己的表述整合方法，未复制书籍章节或第三方文章。以下为作者公开页面；链接可阅读不表示可以再分发整本作品。

- [Performance Analysis Methodology](https://www.brendangregg.com/methodology.html)：方法总览及问题陈述、工作负载、科学方法等。
- [USE Method](https://www.brendangregg.com/usemethod.html)：每个资源的 utilization、saturation、errors。
- [TSA Method](https://www.brendangregg.com/tsamethod.html)：从线程执行、排队、换页、睡眠、锁与空闲状态解释时间。
- [Off-CPU Analysis](https://www.brendangregg.com/offcpuanalysis.html)：按阻塞栈聚合 off-CPU 时间。
- [Linux Performance Analysis in 60s](https://www.brendangregg.com/blog/2015-12-03/linux-perf-60s-video.html)：Linux 初筛清单。
- [Performance Checklists for SREs](https://www.brendangregg.com/blog/2016-05-04/srecon2016-perf-checklists-for-sres.html)：分层清单与方法化调查。
- [Active Benchmarking](https://www.brendangregg.com/activebenchmarking.html)：运行基准时观测组件，解释实际限制因素。

案例测量与脚本来自本项目独立实验，不是作者演讲中的结果。原始清单年代较早；命令字段和事件支持应以目标系统实际行为为准。
